# mini-chatbot
A simple rule-based chatbot built using Python.  
It can respond to greetings, basic questions, and exit commands.
## Features
- Responds to greetings (hi, hello, hey)
- Answers simple questions
- Handles exit commands (bye, quit, exit)
- Randomized replies for a natural feel
- Beginner-friendly and easy to understand
## Tech Stack
- Python 3
- Built-in `random` module
