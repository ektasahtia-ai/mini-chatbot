# ChatPy – Smart Python Chatbot

A smart beginner-friendly chatbot built using Python.  
ChatPy can respond to greetings, remember your name, tell jokes, share facts, motivate users, perform simple calculations, and more.

---

## Features

- Responds to greetings
- Remembers user names
- Mood detection
- Random jokes
- Fun facts
- Motivation messages
- Shows current time
- Basic calculator support
- Handles exit commands
- Randomized responses for natural conversations

---

## Tech Stack

- Python 3
- Built-in `random` module
- Built-in `datetime` module

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ChatPy.git
```

### 2. Open the project folder

```bash
cd ChatPy
```

### 3. Run the chatbot

```bash
python chatbot.py
```
